# Entscheidungen

Kurze Vermerke über Entscheidungen, die man später hinterfragen wird — und über
die Gründe, die man dann nicht mehr im Kopf hat.

Eine Entscheidung gehört hierher, wenn sie schwer zurückzunehmen ist, wenn sie
eine naheliegende Alternative verwirft, oder wenn jemand sie beim Lesen des Codes
für einen Fehler halten könnte.

**Auch eine Ablehnung braucht Deckung** (`AGENTS.md` §10). Wer etwas nicht baut
und den Grund erfindet, hat keine Entscheidung getroffen, sondern eine Ausrede
aufgeschrieben. Der Abschnitt „Verworfen" ist deshalb Pflicht, nicht Zierat.

## Aufbau

```markdown
# NNNN — Titel

**Stand:** vorgeschlagen | angenommen | überholt durch NNNN
**Datum:** JJJJ-MM-TT

## Lage
## Entscheidung
## Verworfen
## Folgen
```
